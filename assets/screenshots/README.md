# Public screenshot requirements

This directory is reserved for reviewed screenshots used by the public project page. Screenshot images are intentionally pending capture and privacy review.

The planned filenames are:

- `main-window.png`
- `search-results.png`
- `message-preview.png`

Every public screenshot must be created from purpose-built synthetic PST, EML, or MSG content. It must not contain:

- real names;
- real email addresses;
- real PST, EML, or MSG data;
- private file paths, account names, or volume names;
- employer information;
- customer information;
- internal ticket numbers;
- access tokens, credentials, or other identifiers; or
- notifications, Finder sidebars, diagnostics, or other background content that reveals private information.

Use fictional people, `example.com` addresses, neutral subjects, and non-sensitive attachments. Do not adapt or lightly redact a real mailbox.

Before committing a screenshot:

1. Inspect every pixel at full resolution.
2. Confirm that the visible state represents actual application behavior.
3. Remove image metadata that could identify a user, device, or location.
4. Have a second person verify that the image contains only synthetic content.
5. Confirm that the filename matches its intended README placeholder.

See the broader [public screenshot procedure](../../docs/SCREENSHOTS.md) for the complete capture and review checklist.
