# Project license decision

Decision date: 2026-07-16

The project owner selected `GPL-3.0-or-later` for PST QuickView's original source code. The official GNU GPL version 3 text is stored byte-identically in the root [LICENSE](../LICENSE) and [LICENSES/GPL-3.0-or-later.txt](../LICENSES/GPL-3.0-or-later.txt).

The bundled ReadPST/LibPST component remains independently licensed under `GPL-2.0-or-later`; its official GNU GPL version 2 text is stored in [LICENSES/GPL-2.0-or-later.txt](../LICENSES/GPL-2.0-or-later.txt). Other dependencies retain their own licenses. Project metadata uses the SPDX identifier `GPL-3.0-or-later` and does not relicense third-party components.

The project-license decision and official texts are complete. The `v0.2.0-beta.3` prerelease publishes the verified ReadPST Corresponding Source package beside the DMG. Remaining review and future-release requirements are tracked in [RELEASE_COMPLIANCE.md](RELEASE_COMPLIANCE.md).
